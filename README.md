# Brenda González Solís — Sitio web

Powered by: Brinza Solutions

## Archivos
- `index.html` — Propuesta A · Jardín Nocturno
- `manuscrito.html` — Propuesta B · Manuscrito (renómbrala a `index.html` si prefieres esta)
- `obras.js` — datos de las obras (títulos, años, medidas, descripciones ES/EN) y biografía. Edita aquí para cambiar textos.
- `support.js` — runtime necesario para las páginas
- `assets/` — imágenes (obras recortadas en `assets/obras/`, fotos, marcos y ornamentos)

## Publicar en GitHub Pages
1. Crea un repositorio y sube todo el contenido de esta carpeta a la raíz.
2. Settings → Pages → Source: "Deploy from a branch", rama `main`, carpeta `/ (root)`.
3. El sitio queda en `https://<usuario>.github.io/<repositorio>/`.
